---
title: Sipdb
---

Sipdb menyalin database produksi MySQL/MariaDB ke database lokal di
laptopmu. Server hanya dibaca, tidak pernah ditulis.

Sipdb copies your production MySQL/MariaDB database to a local database on
your laptop. The server is only read, never written.
